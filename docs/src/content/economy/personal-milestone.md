---
title: Personal milestones
description: A bar that fills only when you give bits to the server. Each stage pays a little back.
---

Your **milestone bar** fills only when you [give bits to the server pool](/commands/pool). Shop purchases do not count. The bar is yours. The pot is the server's. The same gift updates both.

Each stage costs twice the one before it. Five is meant to be reachable. Ten is the last stage. Leftover bits stay on the bar, and you claim one stage at a time.

Claiming pays the bits immediately. It does not grant the prestige reward on that row. That reward is stamped only if you [prestige](/prestige/overview) after the stage is claimed.

## The ten stages

| Stage | Bits you need to have given | Bits you get back | If you prestige after this |
| --- | --- | --- | --- |
| 1 | 250 | 200 | |
| 2 | 500 | 350 | |
| 3 | 1,000 | 600 | |
| 4 | 2,000 | 1,000 | |
| 5 | 4,000 | 2,000 | Prestige opens. No permanent buff. |
| 6 | 8,000 | 3,500 | Burns pay 1% more. |
| 7 | 16,000 | 6,000 | Grab cooldown is 1% shorter. |
| 8 | 32,000 | 10,000 | Drop cooldown is 1% shorter. |
| 9 | 64,000 | 18,000 | Mints are a little more likely. |
| 10 | 128,000 | 30,000 | Main characters are 1% more likely. |

The "bits you need" is the size of that stage, not a running total of the whole cycle. After you claim stage 1, the 250 is spent from the bar and stage 2 asks for another 500.

[`/milestone`](/commands/milestone) lists all ten, which stage you are on, how many bits are left until the next stage, and which prestige buffs you would keep if you prestiged right now. The current stage is drawn as a bar. `/milestone claim` takes the next payout when the bar has reached it.

The Economy page shows the same list and a Claim button when a stage is ready.

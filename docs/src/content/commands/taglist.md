---
title: Tag list
description: See the tags a player has created.
command: taglist
shortcuts: tags, tl
---

**/taglist** lists a player's tags, the emoji for each one, and how many of their cards use it. ◾ is the mark on cards that have no tag.

## Parameters

| Name | Required | What it is |
| --- | --- | --- |
| `user` | No | Whose tags to look at. A mention in text commands. Defaults to you. |

## Aliases

`tags`, `tl`. `atags`, `atl`, and `ataglist` work.

## Example usage

```
/taglist
atl
ataglist @friend
```

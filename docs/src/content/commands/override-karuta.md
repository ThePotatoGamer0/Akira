---
title: Override Karuta
description: Let Akira also answer k and k! while a server moves off Karuta.
---

`aoverridekaruta` is a text command for server admins. There is no slash command.

Akira asks **Are you sure?** Turning it on makes that server listen for `k` and `k!` as well as `a`, so `kdrop` and `k!view` reach her. She will answer the same commands Karuta would, so Karuta's prefix has to be changed first.

Run `aoverridekaruta` again to turn `k` and `k!` back off.

## Parameters

None. Extra words mean the message is ignored.

## Example usage

```
aoverridekaruta
```

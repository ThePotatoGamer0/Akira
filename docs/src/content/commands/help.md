---
title: Help
description: A short overview of how to play, and a saved Discord name for the WebUI.
command: help
---

**/help** tells you the main commands: drop, grab, collection, view, burn, daily, lookup, cooldowns, wishlist, and frame. It also points at shop, pool, milestone, and prestige. It stores your Discord username so the [WebUI](/webui/authentication) can find you.

## Parameters

None.

## Aliases

No short alias. `ahelp` works.

## Example usage

```
/help
ahelp
```

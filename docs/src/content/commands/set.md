---
title: Set
description: Choose the channel where Akira drops cards. An admin runs this once per server.
command: set
---

**/set** picks the channel the command was used in. Akira drops cards there, and she starts answering commands in that server. Run it again in a different channel to move drops.

A new server stays quiet until an admin does this. The server named by `DISCORD_GUILD_ID` is already set up when `DISCORD_DROP_CHANNEL_ID` is set.

## Parameters

None. The channel is the one you type in.

## Aliases

No short alias. `aset` works.

## Example usage

```
/set
aset
```

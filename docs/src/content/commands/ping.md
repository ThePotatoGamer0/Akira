---
title: Ping
description: Check that Akira is online, and save your Discord name for the WebUI.
command: ping
---

**/ping** answers if she is online. Like [help](/commands/help), it stores your Discord username for the browser sign-in.

## Parameters

None.

## Aliases

No short alias. `aping` works.

## Example usage

```
/ping
aping
```
